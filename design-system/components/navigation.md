# Navegación

`navigationGroups` es la única fuente de la navegación visible. Cada destino tiene icono Lucide, label en español y permiso asociado. El active state combina `aria-current="page"`, fondo sutil y rail gold.

Desktop: sidebar sticky de 240px y topbar de 72px. Tablet (≤1100px): sidebar drawer con backdrop. Móvil (≤600px): topbar compacto, búsqueda desplegable y navegación rápida inferior cuando aplica. Mantén skip link, Escape para cerrar drawer y focus visible.
