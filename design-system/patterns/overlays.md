# Patrón: overlays y confirmación

**Propósito:** editar, revisar o confirmar sin abandonar la tarea actual.

Usa modal para una decisión acotada, drawer para navegación/contexto lateral y popover para filtros cortos. Para operaciones irreversibles explica el alcance exacto, usa botón danger y exige confirmación explícita. Nunca conviertas un warning de importación o reemplazo en un CTA ambiguo.
